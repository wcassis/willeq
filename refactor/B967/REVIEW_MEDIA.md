# review/B967 -- file inventory (no verdicts)

Location: `/mnt/projects/fable/review/B967/` (NFS, Pi + Synology).
Builds: `before_d3375b65` = CI `build-arm` job 2063 (`fable` d3375b65);
`after_9e57bc4d` = CI `build-arm` job 2068 (this branch 9e57bc4d).

## arm_bin/
ARM binaries (Orange Pi One, Mali 400, Mesa prefix 25.2.8, `-nollvm`).
- `after_9e57bc4d/` and `before_d3375b65/` each contain four:
  `gles2_zone_benchmark` (+ `-nollvm`) and `gles2_player_light_probe` (+ `-nollvm`).
  The `-nollvm` variants are the ones used by all Pi runs (DT_RPATH absolute,
  no `$ORIGIN`, no libLLVM); the plain variants are the CI's default output.

## pi_frame_time_ab.tsv
Frame-time A/B: 5 zones x 60 frames each, before/after interleaved per zone
in one session. Columns: total_p50, total_p95, gpu_p50, cpu_p50 (before/after,
delta_p50_pct, delta_p95_pct). Generated by `pi/run_timing.sh`.

## pi/
### pi/gate/<zone>_after/  (5 zones: qeynos2, gfaydark, befallen, iceclad, timorous)
The Pi gate frames rendered by the `after_9e57bc4d` binary with B960's gate
poses (`/mnt/projects/fable/review/B960/pi/gate_poses.tsv`). Per zone:
- `<zone>_f0.png`, `<zone>_f1.png`, `<zone>_f2.png` -- 800x600 gate frames
- `<zone>.csv` -- per-frame benchmark metrics (frame, pos, heading, pitch,
  cpu_ms, gpu_ms, total_ms, draws, polys, regions_*, light_radius, ...)
- `bench.log` -- benchmark stdout/stderr
- `mesa_maps.log` -- loaded libgallium path (proves Mesa 25.2.8 prefix, no libLLVM)
Generated by `pi/run_gate_poses.sh`.

### pi/probe/after/
`gles2_player_light_probe --assert` output on the Pi with the `after_9e57bc4d`
binary. The probe draws a large wall and a 40,000-unit quad at two origins
(0,0,0 and the iceclad f2 gate pose) and samples the player-light contribution
per probe column.
- `origin0.csv` / `origin0.log` -- probe columns at origin (0,0,0);
  the CSV is the per-column light value; the log has the benchmark preamble.
- `far.csv` / `far.log` -- probe columns at the 40,000-unit quad origin;
  verifies the light is 0 past R.
- `assert.log` -- the on-Pi `--assert` verdict. Predates the 1-step FP16
  tolerance added in 98846a79; says FAIL on the strict rule only.
- `assert_offline_final_criterion.txt` -- the final criterion recomputed
  offline from the same Pi pixels, with the 1-step tolerance; PASS.
- `pp_instr_counts.tsv` -- Mali-400 per-pixel instruction count
  (`LIMA_DEBUG=pp`): variant x surface; `ship` and `prod` both 9 on the wall
  (B965's pre-B967 `prod_saturate` was 10).

### pi/timing/<zone>_ab_{before,after}/
Raw per-frame CSVs and benchmark logs behind `pi_frame_time_ab.tsv`.
5 zones x 2 runs (before_d3375b65 / after_9e57bc4d), 60 frames each.
Generated by `pi/run_timing.sh`.

### pi/run_gate_poses.sh, run_probe.sh, run_timing.sh
Pi-side wrappers: gate frames, probe, and timing A/B. The gate-poses script
accepts a binary path and a comma-separated zone list; output lands in
`review/B967/pi/gate/<zone>_<tag>/` on NFS.

## scripts/
- `regen_goldens.py` -- regenerates `tests/goldens/*.png` by calling
  `scripts/ci/visual_gate.py run_benchmark()` per manifest zone, twice
  (run1 and run2 must be pixel-identical; a non-zero run1-vs-run2 diff is an
  error). Installs the run2 PNGs into `tests/goldens/`. The committed goldens
  in this branch come from this script.
- `contact_sheet.py` -- builds the before/after/diff contact sheets in `sheet/`.
