# E04: EQE1Loader Class — mmap Reader with Name Lookup

## Overview

Runtime loader class that opens `.eqe1` flat pack files and provides O(1) texture lookup
by name. Returns pointers to pre-compressed ETC1 data ready for `glCompressedTexImage2D`.
No GL calls — this class is thread-safe and can be used from any thread.

## Prerequisites

- E01 complete (EQE1 format header)
- E02 complete (at least one .eqe1 file exists for testing)

## Plan

### Step 1: Create `include/client/graphics/eqe1_loader.h`

```cpp
#pragma once
#include "client/graphics/eqe1_format.h"
#include <string>
#include <unordered_map>
#include <vector>

namespace EQT { namespace Graphics {

class EQE1Loader {
public:
    EQE1Loader();
    ~EQE1Loader();

    // Non-copyable, movable
    EQE1Loader(const EQE1Loader&) = delete;
    EQE1Loader& operator=(const EQE1Loader&) = delete;
    EQE1Loader(EQE1Loader&&) noexcept;
    EQE1Loader& operator=(EQE1Loader&&) noexcept;

    // Open an .eqe1 file. Returns false on error.
    bool open(const std::string& filepath);

    // Close and release resources.
    void close();

    // Texture entry info returned by lookup.
    struct TextureEntry {
        const uint8_t* data;        // pointer into file buffer
        uint32_t dataSize;          // total ETC1 data bytes (all mip levels)
        uint16_t width;
        uint16_t height;
        uint8_t  mipLevels;
        bool     hasAlpha;
        const uint8_t* alphaData;   // nullptr if opaque
        uint32_t alphaDataSize;     // 0 if opaque
    };

    // Look up texture by lowercase name. Returns nullptr if not found.
    const TextureEntry* lookup(const std::string& name) const;

    // Get raw data entry (e.g., .wld file). Returns false if not found.
    bool getRawData(const std::string& name, const uint8_t*& data, uint32_t& size) const;

    // List all texture names (for diagnostics / preloading).
    std::vector<std::string> getTextureNames() const;

    // List all raw data entry names (for diagnostics).
    std::vector<std::string> getRawDataNames() const;

    // Stats
    uint16_t getEntryCount() const;
    const std::string& getFilePath() const;
    bool isOpen() const;

private:
    std::string filepath_;
    std::vector<uint8_t> fileData_;          // entire file contents
    std::unordered_map<std::string, TextureEntry> textureLookup_;
    std::unordered_map<std::string, std::pair<const uint8_t*, uint32_t>> rawDataLookup_;
    uint16_t entryCount_ = 0;
    bool isOpen_ = false;
};

}} // namespace EQT::Graphics
```

### Step 2: Create `src/client/graphics/eqe1_loader.cpp`

#### 2a: `open()` implementation

1. Read entire file into `fileData_` vector via `std::ifstream` (binary mode)
   - File sizes are small (1-20 MB typically). Full read is fine.
2. Validate file size ≥ `sizeof(EQE1Header)` (16 bytes)
3. Cast `fileData_.data()` to `const EQE1Header*`, validate:
   - `magic == EQE1_MAGIC`
   - `version == EQE1_VERSION`
   - File size ≥ header size + numEntries × `EQE1_INDEX_ENTRY_SIZE`
4. Read index entries from offset 16:
   - Cast to `const EQE1IndexEntry*` array
   - For each entry, validate:
     - `dataOffset + dataSize ≤ fileData_.size()`
     - `dataOffset % 16 == 0` (alignment check)
     - `entryType` is 0, 1, or 2
5. Build `textureLookup_` map:
   - For `entryType` 0 or 1: create `TextureEntry` with data pointer = `fileData_.data() + entry.dataOffset`
   - For `hasAlpha=1`: after all entries are indexed, look up `{name}_alpha` companion and set `alphaData`/`alphaDataSize` pointers
   - Key: lowercase name string (copy from entry.name, strip null padding)
6. Build `rawDataLookup_` map:
   - For `entryType` 2: store pointer + size
7. Log: filename, entry count, texture count, alpha count, raw data count
8. Return true on success, false on any validation failure (log error)

#### 2b: `lookup()` implementation

1. Find name in `textureLookup_` (already lowercase)
2. Return pointer to `TextureEntry` or nullptr

#### 2c: `getRawData()` implementation

1. Find name in `rawDataLookup_`
2. Set output pointer and size, return true/false

#### 2d: `close()` implementation

1. Clear `textureLookup_`, `rawDataLookup_`
2. Clear `fileData_` (releases memory)
3. Set `isOpen_ = false`

#### 2e: Move constructor/assignment

Transfer ownership of `fileData_`, lookup maps, state. Source becomes closed.

Create `tests/test_eqe1_loader.cpp`:

   - Verify `open()` returns true

   - Verify `TextureEntry` has correct width, height, mipLevels
   - Verify `data` pointer is non-null
   - Verify `dataSize` matches `etc1MipChainSize()`

c. **Test: Lookup nonexistent texture**
   - Returns nullptr

d. **Test: Alpha texture companion**
   - Look up a texture with alpha
   - Verify `hasAlpha == true`
   - Verify `alphaData` is non-null and `alphaDataSize > 0`

e. **Test: Raw data entry**
   - Look up a .wld entry
   - Verify data matches original WLD bytes

f. **Test: Invalid file**
   - `open()` on nonexistent path returns false
   - `open()` on file with wrong magic returns false
   - `open()` on truncated file returns false

g. Add test to CMakeLists.txt test section.
