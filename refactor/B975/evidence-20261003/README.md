# Compact evidence from the guided run

Renderer commit: `c778d23dab9024a55c983c62bf61169453f2a2bb` (pipeline 483).
Raw logs and PNGs: `~/kb-evidence/b975-name-tags/codex-20261003/` on hermes-ext.

- `pi-drawcost.csv`: verbatim `pi-micro/drawcost/drawcost.csv`, generated by
  the published `nametag_drawcost-nollvm drawcost` on the locked Pi, 800x600.
- `pi-pixel.csv`: verbatim `pi-micro/pixel/pixel.csv`, same tool's `pixel`
  mode; primary comparisons and intentional tie-order variant are separate.
- `x86-pixel.csv`: verbatim `x86-micro/pixel/pixel.csv`, CI-built x86 tool.

The parent README records acceptance status. Small CSVs are committed;
bulk logs and screenshots remain in the external evidence directory.

- `pi-verification.csv`: selected unmodified verifier columns plus variant
  and source path, from each valid run's result TSV. Memory is net of PNGs.
- `pi-timing.md`: generated by `scripts/b975/frametiming_table.py` from the
  eight valid Pi runs. FPS estimates are CPU timings, not presentation FPS.
- `pi-crowd.md`: generated by `scripts/b964/crowd_table.py`; its raw memgpu
  memory includes tmpfs PNG charges. Use the verifier CSV for net memory.

- `x86-verification.csv`: final-zone ready/steady, exit/watchdog/FATAL and
  raw memory scalars from each x86 client log. Generated by the external
  evidence directory's `summarize-x86.py`; zero exits are not memory passes.
- `x86-timing.md` / `x86-crowd.md`: the same in-tree table scripts applied to
  `x86-crowd/`. llvmpipe timing is not Pi performance evidence.

- `live-tags-comparison.json`: pixel counts from the saved live PNG pairs,
  generated by `compare-live-tags.py` in the external evidence directory.
  Colour masks use fixed rectangles chosen after viewing the batch images;
  this is a scoped check, not a whole-frame or aesthetic approval.
