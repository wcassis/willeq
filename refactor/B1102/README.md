# B1102 — hotbar close box removal (#422)

Will ruled on 2026-10-20 that the hotbar must not have a close button. The
stock XML's `Style_Closebox true` does not override that ruling. The page-row
strip remains 12px tall, now named `kPageRowH` for its page buttons.

## Behaviour and toggle route

The hotbar has no close-box geometry, draw, hover state, hit or click arm.
The former 800x600 close-box centre `(750,492)` is inert window frame:
clicking it consumes the frame point without changing `isOpen` or sending an
intent (`StaticUIInputTest.HotbarOldCloseBoxIsInertFrame`).

Alt+H is the existing `ToggleHotbar1Window` action. Its binding is in
`HotkeyManager`; the renderer action calls `FrameComponent::toggleHotbar1Window()`
and flips `isOpen`. The Options > Keys > Hotbar 1 page lists the rebindable
action. `HotbarKeyRoutingTest` pins the keyboard, renderer and Options Keys
paths. There is no `/hotbar` slash-command toggle.
